# Panorama Water Tank Monitor — Security Policy & Vulnerability Disclosure

---

### 1. Supported Software Versions

Security patches and dependency updates are actively maintained for the following releases:

| Version | Release Status | Security Support Level |
|---|---|---|
| **2.0.x (NextGen)** | Active Stable Release | Supported (Critical & High CVE Patches) |
| **1.0.x (Legacy C++/Qt)** | Deprecated | EOL (Unsupported) |

---

### 2. Reporting a Vulnerability

The Panorama Water Tank Monitor project takes software security seriously:

- **Private Reporting:** If you discover a security vulnerability, please submit a report through **GitHub Private Vulnerability Reporting** via the "Security" tab of this repository.
- **Responsible Disclosure:** We request that security researchers maintain confidentiality until an authorized fix and remediation report have been reviewed and published.
- **Scope:** Please report issues including remote code execution, SQL injection, authentication bypass, path traversal, sensitive credential exposure, or physical telemetry corruption.
- **Response Timeline:** Initial acknowledgment within 48 hours; assessment and remediation plan within 5 business days.
